## 0. 한 줄 정의

**kalimagic-v2를 직접 업그레이드.** 단, 사이트 구조는 **랜딩 페이지 1(`kalis_magic_playground/`)의 멀티 페이지 구성**을 따른다 — 단일 스크롤 페이지가 아니라 nav로 연결된 여러 페이지. index는 nav가 붙은 **일반 홈페이지**이고, 리드 수집·라이트 레슨 신청은 별도 페이지(입문·레슨)에서 처리한다.

## 2. 리드 수집의 핵심 목표 (North Star)

index는 일반 홈이므로 전환 목표는 **입문(intro) 페이지**가 진다.

**현재 (무료 강의 영상 제작 전):** 방문자 → 입문 페이지 → 스모어 폼 제출(라이트 레슨 신청 + 계좌이체).

**무료 강의 완성 후:** 방문자 → 영상/입문 페이지 → 스모어 폼 제출(연락처 확보) → nurture → 라이트 레슨 전환.

- index(홈)는 욕구 후킹 + 칼리형 소개 + 작품/입문으로 자연 유도. 직접 전환은 입문·레슨 페이지에서.
- 입문 페이지의 모든 요소(헤드라인·후기·버튼)가 하나의 폼 제출을 향한다.

---

## 3. 타겟 — 하나로 묶은 한 사람

"사람들 앞에서 기억에 남고 싶은데(욕구), 그 수단으로 마술을 배워보려는(행동) 사람."

- 마술 초심자 + 사회적 자신감·매력 원하는 사람을 **평행 나열하지 않고 하나로 묶는다.**
- **헤드라인 = 욕구(매력·존재감)로 후킹**, **미끼 = 마술 무료강의 또는 라이트 레슨(수단)으로 연결.**
- 타겟 진짜 욕구 = "낯선 사람·대중 앞에서 당당하고 기억에 남는 존재가 되는 것" (마술은 수단).

---

## 4. 미끼 (리드 마그넷) — 단계별

### 현재 단계 (무료 강의 영상 제작 전)
- **라이트 레슨 직접 신청** — 입문 페이지 → 스모어 폼 → 계좌이체 → 영상 링크 발송.
- CTA: "라이트 레슨 신청하기"

### 무료 강의 완성 후
- **마술 1개 무료 강의 영상** — "공짜인데 이 정도면 유료는 얼마나 좋을까" 기대감으로 라이트 레슨 자연 연결.
- 어떤 마술인지 = **TBD (칼리형 지정 필요)** — 따라 하기 쉽고 즉시 "통하는" 임팩트가 있는 1개 권장.
- 영상은 페이지에서 바로 재생 ❌ → **폼 제출 후 전달** (게이트). 연락처를 받기 위한 교환 조건.
- CTA: "무료 강의 받기"

## 5. index (홈) 구조 — 옵션 조합 ACAAACCCB 단일 랜딩

index는 섹션 옵션 비교에서 확정한 조합 **ACAAACCCB**를 구현한 단일 랜딩이다 (nav 있는 둘러보기 홈).

| # | 섹션 | 목적 | 핵심 메시지 방향 |
|---|---|---|---|
| 1 | Hero (욕구 후킹) | 3초 안에 "내 얘기다" | "마술로 그 자리에서 기억에 남는 사람이 되는 법" |
| 2 | 칼리형 소개 | 신뢰·인물 | "칼리형은 누구?" |
| 3 | 왜 마술일까 | 욕구→수단 연결 | 마술이 왜 사회적 무기인지 |
| 4 | 갤러리 | 비주얼 증거 | 시연·모임 사진 |
| 5 | 후기 | 사회적 증거 | v2/v1 verbatim 후기 (각색 금지) |
| 6 | 작품 CTA | 다음 페이지 유도 | "형이 만든 작품들 한번 봐볼래" → works |
| 7 | 최종 CTA | intro 연결 | 입문 페이지로 전환 유도 |

→ index는 전환 강요가 아니라 **탐색 유도**. 최종 CTA는 intro(입문)로 연결되며, 실제 폼 전환은 intro·레슨 페이지가 전담.

## 6. 전달 방식 (입문 페이지 기준)

### 현재 단계 — 라이트 레슨 직접 신청
1. 방문자가 입문 페이지 CTA 클릭 → **스모어 폼**
2. 스모어 폼에서 적어야 하는 항목 6가지: **이름 / 나이 / 성별 / 휴대폰 번호 / 이메일 / 어디서 알았는지**
3. 칼리형이 계좌번호 안내 → 입금 확인 → 영상 링크 발송 (mmbs 비공개 페이지 또는 직접 전달)

### 무료 강의 완성 후 — 연락처 수집 + nurture
1. 방문자가 영상/입문 페이지 CTA 클릭 → **스모어 폼**
2. 스모어 폼에서 동일 항목 6가지 입력
3. 칼리형이 스모어 통해 무료 강의 영상 링크 전달
4. nurture → 라이트 레슨 전환 제안

→ 랜딩 페이지의 책임은 **"폼까지 보내는 것"**까지. 그 이후는 스모어/칼리형 영역.
