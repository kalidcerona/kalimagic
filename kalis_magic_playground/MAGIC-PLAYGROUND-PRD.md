## 0. 작업 전 체크

1. 작업 유형: 기존 kalimagic 랜딩 사이트에 커뮤니티 기능을 붙이는 업그레이드.
2. 기존 파일만으로는 불가. Google 로그인, DB, API, 관리자 페이지, 권한 모델이 필요하다.
3. 새 agent는 필요 없다. 새 schema/API는 필요하다.
4. 공개 사용자 입력이 생기므로 공개 화면/문구 확정 전 quality-safety-editor 검수가 필요하다.
5. 기록 위치: 설계 결정은 이 문서와 후속 ADR에 기록. 출시/운영 결과는 outcome ledger 후보.
6. 1단계 완료 기준: 칼리형이 승인한 PRD, 영향 분석, ADR/Tech Spec, Migration/Rollback, 구현 계획.
7. 이번 단계에서 하지 않을 것: HTML/CSS/JS 구현, Supabase 프로젝트 생성, Netlify 설정 변경, DB 마이그레이션 실행.

## 1. One-page Brief

### 무엇을 만드는가

칼리형 랜딩 사이트 안에 `마술 놀이터`라는 통합 커뮤니티 게시판을 만든다.

사용자는 Google 로그인 후 질문, 모임 후기, 리뷰/후기, 자유글을 작성할 수 있다. 게시판에서는 `전체 / 질문 / 모임 후기 / 리뷰 / 자유 / 매거진` 카테고리로 글을 볼 수 있다.

### 왜 만드는가

한국 마술인을 위한 양지 커뮤니티가 부족하다. 현재 사람들은 DC나 오픈채팅을 주로 쓰지만, DC는 음지 이미지와 낮은 답변 품질 문제가 있고, 오픈채팅은 질문과 답변이 금방 묻힌다.

`마술 놀이터`는 질문과 답변이 아카이빙되고, 마술의 비밀을 존중하며, 칼리형 기준의 답변 품질 문화를 만드는 공간이다.

### 누구를 위한 것인가

첫 사용자:

- 칼리형 오픈채팅방 사람들
- 칼리형 콘텐츠를 보는 사람
- 2026년 8월 모임 참석자

첫 질문 쐐기:

- "이 마술은 어디서 배워야 하나요?"
- "이 기술/계열은 어떤 책, 렉처, 영상부터 보면 되나요?"
- "입문자는 어떤 순서로 공부하면 좋나요?"

### 성공 기준

출시 후 2-4주 안에 `마술 학습 경로 질문`이 10개 쌓인다.

보조 성공 신호:

- 오픈채팅에서 흘러갈 질문을 사이트 링크로 안내할 수 있다.
- 칼리형 답변이 답변 품질 기준을 보여준다.
- 8월 모임 참석자가 후기 페이지에서 후기를 작성하고, 그 글이 게시판에도 자동 연동된다.

### 이번 버전에서 하지 않을 것

- 직접 영상 업로드
- 참석자 직접 사진 업로드
- 유료 멤버십
- 전문가 답변자 공개 모집
- 자유게시판 중심 운영
- 질문자 동의 없는 비공개 질문 공개 전환

## 2. PRD

### 목적

kalimagic 사이트를 정적 랜딩 페이지에서 `후기가 살아 움직이는 사이트`이자 `한국 마술인들의 구심점`으로 업그레이드한다.

### 제품 원칙

1. 겉은 편한 놀이터, 안쪽은 단단한 규칙.
2. 마술 비밀을 존중한다.
3. 좋은 답변을 아카이빙한다.
4. 운영비는 무료에 가깝게 시작한다.
5. 후원 배지는 권한 구매가 아니라 응원 표시다.
6. 전문가 권한은 칼리형이 신뢰하는 사람에게만 부여한다.

### 핵심 사용자

#### 질문자

마술을 배우고 싶은데 어디서, 어떤 순서로 공부해야 하는지 모르는 사람.

필요:

- 믿을 만한 답변
- 공개/비공개 선택
- 본명 노출 없이 활동
- 내 질문과 답변 확인

#### 모임 참석자

2026년 8월 칼리형 모임에 참석하고, 자기 기억에 남은 순간을 후기로 남기고 싶은 사람.

필요:

- 가이드된 긍정 후기 폼
- 칼리형이 올린 사진 풀에서 2-5장 선택
- 즉시 공개
- 게시판 댓글/답글

#### 칼리형

질문에 직접 답하고, 좋은 답변 문화를 만들고, 후기와 질문을 관리하는 운영자.

필요:

- 새 글 통합 관리
- 답변 대기 질문 확인
- 숨김/복구/삭제
- 매거진 후보 저장
- 나중에 전문가 지정

### MVP 기능

#### Google 로그인

- 모든 글 작성은 Google 로그인 필요.
- 전체 공개 질문도 로그인한 사람만 작성 가능.
- 공개 표시명은 Google 이름이 아니라 사용자가 정한 닉네임 또는 익명.
- 계정 정보는 운영/권한/관리용이고, 공개 화면에는 직접 노출하지 않는다.

#### 통합 게시판: 마술 놀이터

카테고리:

- 전체
- 질문
- 모임 후기
- 리뷰/후기
- 자유
- 매거진

MVP 표시:

- 전체
- 질문
- 모임 후기
- 리뷰/후기

자유/매거진은 구조를 열어두되, 초기 활성화는 선택 사항이다.

#### Q&A

질문 공개 범위:

- 전체 공개
- 칼리에게만 공개
- 전문가 이상 공개

답변 공개 범위:

- 질문자에게만 공개
- 전체 공개

규칙:

- 질문 공개 범위가 상한선이다.
- 비공개 질문은 목록에서 제목만 보인다.
- 비공개 질문의 본문/작성자/답변은 권한 있는 사람만 본다.
- 비공개 질문을 공개 아카이브로 바꾸려면 질문자 승인 필요.
- 좋은 답변은 칼리형에게 매거진 후보로 알릴 수 있다.
- 칼리형은 질문을 각색/익명화해 매거진 글로 발행할 수 있다.

초기 답변자:

- 칼리형만 답변.

확장:

- 질문량이 늘고 운영이 어려워지면 칼리형 기준에서 마술 잘하는 전문가를 부탁해 답변자로 초대한다.

#### 모임 후기

진입점:

- `reviews.html` 후기 페이지에서 작성한다.

노출:

- 후기 페이지에 즉시 표시된다.
- 동시에 `마술 놀이터`의 `모임 후기` 카테고리에도 자동 연동된다.
- 게시판에서는 댓글/답글을 받을 수 있다.

작성 폼:

- 오늘 좋았던 순간
- 인상 깊었던 마술/사람/분위기
- 다음에 보고 싶은 프로그램
- 처음 온 사람에게 해주고 싶은 말
- 선택: 유튜브 링크
- 사진 선택: 칼리형이 올린 행사 사진 풀에서 2-5장

정책:

- 참석자는 직접 사진 파일을 업로드하지 않는다.
- 메인 행사 사진/갤러리와 사진 풀은 칼리형이 직접 업로드한다.
- 후기는 즉시 공개한다.

#### 리뷰/기존 후기

- 기존 후기 카드에는 안정적인 `review_id`가 필요하다.
- 기존 후기 카드에서 댓글/반응을 볼 수 있게 확장 가능.
- 이 기능은 모임 후기와 Q&A보다 우선순위가 낮다.

#### 관리자 페이지

관리자만 접근 가능.

한 번에 볼 것:

- 새 모임 후기
- 새 Q&A
- 자유게시판 새 글, 구조만 준비 가능
- 비공개 질문
- 답변 대기 질문
- 신고/문제 글
- 숨김 처리 글
- 삭제 처리 글
- 매거진 후보

액션:

- 숨김
- 복구
- 삭제
- 답변 작성
- 답변 수정
- 공개 범위 변경
- 매거진 후보 저장
- 전문가 답변자 지정, 나중 기능

### 비요구사항

- 사용자 간 DM 없음
- 채팅 없음
- 직접 영상 업로드 없음
- 직접 사진 업로드 없음
- 결제 자동화 없음
- 후원 배지는 초기 표시 설계만 가능, 실제 결제/정산은 후속

### 위험 요소

- Google 로그인까지 포함하면 MVP 범위가 커진다.
- 비공개/전문가 공개 권한 모델을 잘못 만들면 정보 유출 위험이 있다.
- 즉시 공개 후기는 관리자 페이지가 없으면 운영 리스크가 있다.
- 무료 티어 운영은 초기에는 가능해 보여도 실제 트래픽/스토리지에 따라 제한될 수 있다.
- `마술 놀이터`가 너무 넓게 시작하면 Q&A 쐐기가 흐려질 수 있다.

## 4. Design Doc / Tech Spec

### 권장 아키텍처

```text
static HTML/CSS/JS
-> community/playground JS
-> Netlify Functions API
-> Supabase Postgres
-> Supabase Auth / Google OAuth
```

이전 참고자료의 핵심 결론은 유지한다. 단, 이번 정식 설계에서는 Google 로그인을 MVP에 포함한다.

### 왜 이 구조인가

- 기존 kalimagic 사이트를 유지한다.
- 운영비를 무료에 가깝게 시작할 수 있다.
- Google 로그인으로 비공개 질문 접근 권한을 안전하게 다룰 수 있다.
- 서버 함수가 공개/비공개/전문가 권한을 강제한다.
- Supabase는 Auth와 Postgres를 함께 제공해 작은 팀 MVP에 맞다.

### 주요 파일

기존 파일:

- `reviews.html`: 모임 후기 작성 진입점, 기존 후기 카드 확장.
- `modal.js`: 기존 후기 모달 유지. 필요하면 커뮤니티 댓글 슬롯만 추가.
- `style.css`: `.community-*`, `.playground-*`, `.admin-*`처럼 새 스코프 사용.
- `nav.js`: 마술 놀이터 링크 추가.

새 파일 후보:

- `playground.html`: 마술 놀이터 통합 게시판.
- `admin.html`: 관리자 페이지.
- `auth.js`: Google 로그인/session helper.
- `community.js`: 게시판 공통 UI/API client.
- `reviews-community.js`: 후기 페이지 작성/사진 선택/연동 UI.
- `netlify.toml`: publish 범위와 functions 위치 정의.
- `netlify/functions/*.js`: API.
- `supabase/migrations/*.sql`: schema/RLS/index.

### 데이터 모델 방향

핵심은 "하나의 게시판처럼 보이되, 타입별 요구사항은 분리"다.

권장 최소 테이블:

- `profiles`: user_id, nickname, role, display defaults.
- `posts`: 통합 게시판의 공통 필드.
- `questions`: Q&A 전용 세부 필드.
- `answers`: Q&A 답변.
- `event_reviews`: 모임 후기 전용 세부 필드.
- `event_review_photos`: 후기에서 선택한 사진 연결.
- `event_photos`: 칼리형이 업로드한 행사 사진 풀.
- `comments`: 게시글 댓글.
- `comment_replies`: 댓글 답글 또는 parent_comment_id 방식.
- `moderation_events`: 숨김/복구/삭제/범위변경 이력.
- `badges`, `user_badges`, `support_records`: 후원/전문가/칼리 배지 확장.

`posts` 공통 필드 후보:

- `id`
- `post_type`: `question`, `event_review`, `review_comment`, `free`, `magazine`
- `category`
- `title`
- `body`
- `author_user_id`
- `display_mode`: `nickname`, `anonymous`
- `visibility`: `public`, `kali_only`, `expert_only`
- `status`: `visible`, `hidden`, `deleted`
- `created_at`, `updated_at`

### 공개 범위 규칙

질문:

- 전체 공개: 모든 방문자가 볼 수 있다.
- 칼리에게만 공개: 질문자와 칼리형만 본다.
- 전문가 이상 공개: 질문자, 칼리형, 전문가만 본다.

비공개 질문 목록:

- 제목은 보인다.
- 본문은 권한자만 본다.
- 작성자는 목록에서 숨김 또는 모자이크.

답변:

- 질문자에게만 공개
- 전체 공개

답변 공개 범위는 질문 공개 범위를 넘을 수 없다.

비공개 질문 공개 전환:

- 질문자 승인 없이는 원문 공개 전환 불가.
- 좋은 답변은 매거진 후보로 저장 가능.
- 매거진은 질문을 각색/익명화해 별도 콘텐츠로 발행.

### 보안 원칙

- 브라우저에는 Supabase secret/service_role key 노출 금지.
- 쓰기/관리 액션은 Netlify Functions를 통과.
- 모든 사용자 입력은 `textContent` 또는 안전한 DOM API로 렌더링.
- 공개 API는 권한 없는 데이터의 제목/본문/작성자/답변을 반환하지 않는다.
- 비공개 질문 본문은 권한 확인 후 반환한다.
- 관리자 페이지는 Google 로그인 + DB role 확인.
- YouTube 링크는 allowlist URL에서 `video_id`만 추출.
- 사용자가 직접 영상/사진 파일을 업로드하지 않는다.

### 무료 운영 전략

초기:

- Netlify Free + Functions
- Supabase Free + Auth + Postgres
- 이미지 파일은 칼리형이 직접 최적화해서 정적 assets로 업로드
- 유튜브는 링크만 저장

주의:

- 실제 출시 전 Supabase/Netlify 무료 quota 재확인 필요.
- Netlify 무료 플랜은 hard limit 성격이 있으므로 갑작스런 과금보다 사용 제한 위험이 크다.
- 트래픽이 늘면 후원 배지/서버비 후원 안내를 붙인다.

### 관리자 페이지 MVP

관리자 첫 화면은 "통합 인박스"다.

필터:

- 댓글/답글

### 기존 사이트와 충돌 지점

## 7. 승인 대기 질문

1. `마술 놀이터` 첫 MVP 범위는 통합 게시판 + Q&A + 모임 후기 + 관리자 페이지로 간다.
2. 자유/매거진은 구조만 열어두고 첫 출시에서 최소화한다.
3. 모든 글 작성은 Google 로그인 필요.
4. 전체 공개 질문은 닉네임/익명 표시 선택 가능.
5. 비공개 질문은 목록에 제목만 보이고, 본문은 권한자만 본다.
6. 모임 후기는 후기 페이지에서 작성하고, 게시판에 자동 연동되며 댓글/답글을 받는다.
7. 모임 후기는 칼리형이 올린 사진 풀에서 작성자가 2-5장을 고른다.
8. 모임 후기는 즉시 공개한다.
9. 좋은 비공개 답변은 원문 공개가 아니라 매거진 후보로 모으고, 질문을 각색/익명화해 발행한다.

위 9개가 맞으면 이 문서를 기반으로 적대 리뷰와 구현 계획으로 넘어간다.
