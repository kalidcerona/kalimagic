# Pi Max 연습

52자리 순환 스택을 익히는 연습 앱입니다. 개인판은 `zz14/`, Google 로그인 후 여는 지인판은 `/tools/pimax/`입니다. 지인판 원본은 `distribution-snapshots/pimax/`이며 저장 키와 서비스 워커 캐시만 분리합니다.

## 연습

암기표, 연습, 설정 탭을 사용합니다. 첫 탭은 답 공개, 두 번째 탭은 다음 문제입니다. 탭을 옮겨도 문제와 진행 상황은 유지됩니다.

- 대응: 글자와 숫자의 짝을 떠올립니다. 어느 쪽을 약점으로 눌러도 양방향이 함께 표시되고, 해제도 함께 됩니다.
- 문장 대응: 문장을 보고 전체 숫자열을 떠올립니다. `전체 문장` 또는 `반만`을 선택합니다. 반만은 앞 단어나 뒤 단어를 무작위로 보여 주며, 답에는 전체 문장과 숫자열이 나옵니다.
- 페이지 1: 암기표의 문장과 숫자열을 줄별로 떠올립니다.
- 페이지 2: 홀수 번호의 쪽에서 시작하는 숫자 세 개를 떠올립니다. 1쪽만 실제 원주율 314이며, 21쪽의 계산 답은 NOI / 201입니다.
- 다음 10: 보이는 다섯 자리 다음부터 숫자 열 개를 떠올립니다.
- 생일: 생일로 쪽, 줄, 시작 자리를 찾습니다.

## 생일 페이지 찾는 법

- 쪽 = 일 + 50
- 줄 = 월 × 2
- MMDD(월일) 시작 = 월 + 3
- DDMM(일월) 시작 = 월 + 1

예: 3월 14일 → 쪽 64, 줄 6, MMDD 시작 6, DDMM 시작 4. 앱의 예시는 `birthdayAddress()`로 계산합니다. 2월 29일 허용 · 번호는 1부터. 생일의 줄 번호와 암기표의 줄 번호는 다릅니다.

## 설치와 저장

브라우저에서 열면 설치 안내가 작은 창으로 한 번 나옵니다. 설치 요청을 띄울 수 있으면 `앱 설치`를 누르고, 그렇지 않으면 설치 순서를 보여 줍니다. `나중에`는 이번 실행에서만 창을 닫습니다. 설정 탭의 `홈 화면에 설치` 안내는 계속 사용할 수 있습니다. 설치된 앱으로 실행하면 안내를 숨깁니다. HTTPS 또는 localhost에서 서비스 워커를 등록하고 기존 오프라인 셸 정책을 유지합니다. 새 버전은 기존 앱 창을 모두 닫은 뒤 다음 실행부터 적용됩니다. 지인판의 접근 확인은 계속 필요합니다.

이전 버전 1의 설정, 회차, 기록을 읽습니다. 문제는 모드, 키, 정답 데이터로 검증하며 화면 문구는 현재 문구로 다시 만듭니다. 입력 내용, 공개 여부, 채점 결과, 진행 위치는 보존하고, 대응의 단방향 약점은 양방향으로 확장합니다. 약점은 최대 40항목이며 대응 한 짝을 한 항목으로 셉니다. 양방향 저장으로 최대 50문제를 보관하며, 한도를 넘으면 가장 오래된 항목 전체를 지웁니다. 손상된 저장 값은 덮어쓰지 않습니다. 문장 표시는 기존 설정에 저장합니다. 예전 설정에 설치 안내 닫기 값이 있어도 읽고, 새 설정에는 그 값을 쓰지 않습니다. 저장한 회차가 이어서 문장이나 거짓말이면 대응으로 다시 시작합니다. 그 연습의 기록과 약점은 건너뜁니다. 문장 표시 변경은 다음 문제부터 적용하며 현재 문제의 공개 상태는 유지합니다.

## 로컬 검증

```bash
node --test *.test.mjs
node --check app.mjs
```

`file://` 대신 정적 서버로 엽니다. 실제 휴대폰의 설치 창과 오프라인 실행은 기기에서 별도로 확인해야 합니다. 공개 런타임 파일은 `scripts/build-public.mjs`의 `PIMAX_FILES`와 서비스 워커 셸에 명시되어 있습니다.
