# Pi Max 연습

52자리 순환 스택을 탭으로 확인하며 익히는 개인 연습 페이지입니다. 서버와 계정은 없습니다.

## 열기

이 폴더에서 정적 서버로 엽니다. 브라우저가 `file://`의 모듈을 막으면 페이지가 비어 보일 수 있습니다.

```bash
node --test core.test.mjs
node --check app.mjs
```

화면은 `index.html`, 규칙은 `core.mjs`, 조작은 `app.mjs`입니다.

## 연습

상단은 암기, 연습, 설정입니다. 연습에서 대응, 줄 회상, 홀수 쪽, 다음 10, 생일, 거짓말을 고릅니다. 먼저 답을 떠올린 뒤 `?`를 탭하면 답이 보이고, 같은 버튼을 한 번 더 탭하면 다음 문제로 넘어갑니다. 직접 정답 점수는 입력하지 않습니다. 탭을 바꿔도 지금 문제는 유지됩니다. 기록 지우기는 설정에서 한 번 더 확인합니다.

1쪽만 실제 원주율 314입니다. 홀수 쪽 21의 계산 답은 NOI / 201입니다.

## 현재 제공 범위

한글 독음은 설정에서 켜고 끕니다. 발음은 읽기 도움이며 숫자 대응은 영문 철자를 기준으로 합니다. 문제마다 약점을 켜고 끌 수 있습니다. 연습의 전체 / 약한 것 선택으로 모든 종류의 약점을 다시 봅니다. 이 기기의 회차·기록을 저장하며 손상된 저장 값은 자동 덮어쓰지 않습니다.

로컬 미리보기: http://127.0.0.1:19405/kalis_magic_playground/zz14/

zz14는 로컬 미러입니다. 공개 빌드 목록에는 아직 추가하지 않았으며, 원본 PDF·워크북은 앱에 포함하지 않았습니다. HTTPS 또는 localhost에서 서비스 워커를 등록하며, 실기 설치·오프라인 동작은 별도 확인이 필요합니다.

검증: 탭·약점 기능까지 포함한 총 40개 테스트 통과. 브라우저에서 두 번 탭, 약점 저장 및 약점 복습의 새로고침 복원을 확인했습니다. 초기 레이아웃은 320×740, 412×915, 820×1180에서 확인했으며 실제 휴대폰·태블릿 실기는 미검증입니다.

## 탭 연습

모든 연습 종류에서 입력칸과 단서 없이 문제와 `?` 버튼을 표시합니다. 첫 탭은 답을 공개하고 두 번째 탭은 다음 문제로 넘어갑니다. `약점`은 공개 전후 어느 때든 누를 수 있습니다. 켜면 초록, 끄면 갈색입니다. 이전 설정의 입력 방식 값은 탭 연습으로 전환됩니다.
