# USOTSUKI · 확대 적용 설계

상태: 2026-10-01 승인된 개인 앱 설정 B와 홀덤펍 공연 v3의 A·B 적용 기준. [공통 디자인 SSOT](</Users/sumpie/Desktop/AI/Projects/kalis magic/PRODUCT_DESIGN_SYSTEM.md>)와 [앱별 정체성 기준](</Users/sumpie/Desktop/AI/Projects/kalis magic/docs/product-design/2026-09-30/APP_IDENTITY_MATRIX.md>)를 상속하며 앱별 차이만 기록한다. 이 문서는 설계 계약이며 구현·실기 검증 완료의 증거가 아니다.

## 1. Product / Artifact concept

담당 개념은 **거짓 · 숨긴 것의 누출**, 유물 해석은 **감추려던 것이 작은 신호로 새어 나오는 탐지판**다. 첫 감정은 “가벼운 놀이 뒤의 들킨 듯한 긴장”이다. 의미는 [세계관 원문](</Users/sumpie/Desktop/리소스/magic_apps_worldbuilding_and_concepts.md>) 및 [앱별 정체성 기준](</Users/sumpie/Desktop/AI/Projects/kalis magic/docs/product-design/2026-09-30/APP_IDENTITY_MATRIX.md>)의 USOTSUKI 행에 근거한다. 설정에서 사연을 암시하고 관객 화면에 세계관 설명을 강제하지 않는다.

## 2. Settings UI identity

[공통 디자인 SSOT](</Users/sumpie/Desktop/AI/Projects/kalis magic/PRODUCT_DESIGN_SYSTEM.md>)의 승인된 설정 B를 사용한다. 따뜻한 공통 셸의 얕은 기록 면, 동일한 타이포·필드·버튼·간격이 판단의 70%를 맡는다. 왼쪽 제목·설명 묶음과 오른쪽 크게 확대한 **평평한 선에서 한 번 생기는 작은 균열**의 세로 중심을 맞춘다. 상징은 조작 버튼이 아닌 장식이며 제목과 입력을 가리지 않는다. 현재 실행 설정의 진실이 나올 시도, 소리, 검사 시간, 준비·검사 진동, 시도 초기화, 공연 시작, 사용 방법과 조건부 설치를 공통 설정 B로 정리한다. 입력 ID·저장 키·회차 파싱·유효성·진동 미지원 안내를 보존한다. 과거 app.js의 질문 묶음·리허설을 추가하지 않는다. 승인된 공연 디자인을 고르는 ‘화면 디자인’만 추가하며 ‘딥 그린 테이블’·‘와인 카드룸’을 제공한다. 전용 저장 키 `usotsuki.detector.theme.v1`은 `green`·`wine`만 받고 기본은 `green`이다. 읽기·쓰기 실패에서도 공연은 유지한다. 테마 변경은 회차·진실 설정·검사 시간·소리·진동·홀드 상태를 초기화하지 않는다. 진동 미지원 안내는 숨겨지는 설정 그룹 밖에 두어 설정에서 읽을 수 있게 한다.

스마트폰·태블릿 A–H만 제품 지원 대상으로 삼는다. 좁은 Fold cover에서는 상징의 폭을 줄여 읽기 공간을 보존하고 태블릿 설정은 최대 560px로 중앙 정렬한다. 44px 조작 타깃·48px 주요 행동·safe-area·세로 스크롤·IME 열린 상태의 마지막 행동 접근을 검증한다. PC 전용 UI·설정 버튼·Shift+Esc·desktop 분기는 제거한다. OS·브라우저 식별 차단은 추가하지 않는다. 태블릿 펜·터치, 모바일 폼 키보드·라벨·focus·접근성, 개발·자동화 도구는 보존한다.

## 3. Settings accent / motif / texture / motion

accent **`#95B39C`**, secondary **`#8A6862`**, motif **평평한 선에서 한 번 생기는 작은 균열**, texture **무광 기기 표면**를 [앱별 정체성 기준](</Users/sumpie/Desktop/AI/Projects/kalis magic/docs/product-design/2026-09-30/APP_IDENTITY_MATRIX.md>)의 후보에서 채택한다. 앱 차이 30%는 오른쪽 상징·작은 선택 표식·국소 재질로 표현한다. 공통 배경을 앱 색으로 덮거나 secondary를 본문색으로 쓰지 않는다. 입력·사진·카메라·QR·결과 위에는 재질을 얹지 않는다.

설정 진입에서 “짧은 신호선이 한 번 갈라짐”을 한 번만 짧게 표현할 수 있다. 저장·입력을 기다리게 하지 않고 reduced-motion에서는 정적인 상징을 유지한다. 새로운 공연 효과나 실제 기능을 뜻하는 모션으로 사용하지 않는다.

## 4. Performance UI

**승인된 v3 외형과 기존 마술 동작 유지**. [승인 이미지](</Users/sumpie/Desktop/AI/Projects/kalis magic/docs/product-design/2026-10-01/rollout/usotsuki-performance/v3/holdem-pub-concepts.png>)의 두 형태를 실제 HTML·SVG·CSS로 구성한다. 신호 모니터·중앙 판정·손가락 접촉 버튼이라는 세 요소와 기존 실행 ID를 유지한다. 실제 실행은 [detector.js](</Users/sumpie/Desktop/AI/Projects/kalis magic/kalis_magic_playground/zz7/detector.js>)를 따르며 과거 app.js의 질문·리허설을 도입하지 않는다.

A는 딥 그린의 미세한 펠트 배경, 넓은 상단 신호 유리창, 분리된 중앙 결과와 그 아래 절제된 곡선 테이블 레일, 넓은 직사각형 접촉 패드다. B는 와인 재질·비스듬한 모서리 봉합선, 신호와 중앙 결과를 하나로 묶은 긴 유리창, 지문 왼쪽·문구 오른쪽의 가로 접촉 스트립이다. 큰 원형 계기와 빈티지 하우징은 사용하지 않는다. 결과·신호는 생성 이미지가 아니라 실제 SVG와 상태 문구로 갱신된다. 한국어 제목과 검사 대기·검사 중·취소·진실·거짓의 기존 문구를 보존한다.

검사 시간 0.5-10초·회차·진실 다중 설정·600ms 첫 터치 준비 피드백·조기 해제/이동 취소·판정 시점·소리·진동·visibility 중단·화면 기준 두 손가락 아래 96px 스와이프를 유지한다. 자동 전체화면과 PC 전용 진입을 추가하지 않는다. 테마 변경·공연 시작·시도 초기화·재실행에서도 테마를 유지하며 기존 회차 초기화 계약은 따로 보존한다.

## 5. Performance UI exception

2026-10-01 사용자가 A·B 모두 실제 적용하도록 승인했다. 기존의 표면 변경에만 한정한 계약을 이번 두 화면의 형태·배치 변경으로 확장한다. 기본 재질은 3개의 작은 코드 기반 SVG이고 전면 래스터 이미지를 UI로 쓰지 않는다. 상단 모니터·중앙 판정·접촉 버튼의 접근성 라벨·live 상태 ID는 유지한다. 버튼은 44px 이상, 모서리는 8-16px 계열이며 스마트폰 280/320/390/480px·Fold inner·태블릿과 관련 가로 화면에 대응한다. 공연 콘텐츠는 최대 600px, 좁은 가로 배치는 640px로 중앙에 제한하고 네 방향 safe-area를 반영한다.

직사각형으로 바뀐 접촉 버튼의 실제 경계를 따라야 하므로 `pointOnButton`의 원형 fallback만 실제 사각형 경계 판정으로 바꾸는 예외를 승인받았다. 버튼 자식 요소의 closest fastpath는 유지한다. 패드 모서리는 유효 접촉이고 패드 위·아래 빈 공간은 검사 시작으로 처리하지 않아야 하며 빈 공간의 설정 스와이프도 유효해야 한다. 그 밖의 hold·취소·타이머·회차·소리·진동·제스처 핸들러는 변경하지 않는다.

통과 조건은 A/B 상태 전환·테마 기본/저장/잘못된 값/저장 실패·재실행·진행 중 변경의 상태 보존, 사각형 모서리와 바깥쪽 입력, 취소·진실 회차·검사 시간·96px 스와이프·미지원 안내 가시성의 기능 검사다. [현재 구조](</Users/sumpie/Desktop/AI/Projects/kalis magic/kalis_magic_playground/zz7/index.html>)와 실제 화면에서 큰 원형 프레임·판독 위 질감·무의미한 의료 퍼센트·SaaS 패널이 남지 않았는지 확인한다. 문서의 승인 기록은 실기·배포 완료의 증거가 아니다.

## 6. Forbidden changes

- 실제 생체·AI·의료 판정 주장·색만으로 결과 전달.
- 기존 저장값·키·순서·숨은 상태·비밀 조작·동작 계약을 디자인 작업으로 변경하거나 관객 화면에 노출하는 변경.
- 공통 셸을 앱별 테마·폰트·navigation으로 다시 만들거나 상징을 여러 곳에 반복하는 변경.
- PC 전용 제품 UI를 되살리거나 OS·브라우저로 실행을 차단하는 변경. 모바일 폼 키보드·태블릿 펜·접근성·개발 자동화를 일괄 제거하는 변경.

## 7. Signature detail

설정 헤더 오른쪽의 **한 번 갈라지는 짧은 신호선**. 제품명과 색을 가려도 형태로 개별 정체성이 구분되어야 한다. 평평한 선에서 한 번 생기는 작은 균열이 거짓과 숨긴 것의 누출이라는 의미를 한 지점에서 전달하고, 셸·입력의 공통 정렬은 같은 제품군임을 보여준다. 공연은 승인된 홀덤펍 v3의 두 구성을 사용하고 설정의 세계관 상징을 추가로 노출하지 않는다.
