# 멤덱 연습실 디자인

## 1 Product / Artifact concept

멤덱 연습실은 Redford와 Mnemonica의 52장 순서를 카드와 번호로 익히는 학습 도구다. 암기, 퀴즈, 포카드, 기억 훈련, 표, 기록, 설정은 하나의 어두운 기록면 위에 놓인다. 첫 화면은 큰 영웅 이미지가 아니라 제목, 스택 선택, 바로 누를 수 있는 메뉴다.

## 2 Settings UI identity

상단 정체성은 모든 탭이 공유한다. 왼쪽은 멤덱이라는 표식과 제목, 한 줄 설명이다. 오른쪽은 카드 윤곽과 위치 번호 17이 세로 중앙에 맞춘 색인이다. 설정은 같은 헤더 아래에서 최대 560px 열에 백업, 순서, 설치 안내, 출처만 둔다. 설정 안에 두 번째 대형 표지를 두지 않는다.

## 3 Settings accent / motif / texture / motion

바탕 #1a1512, 기록면 #1f1815 / #261d18, 올린 면 #34261e, 넣은 면 #17120f. 글자는 #f4efe9, 보조 #ab9f92, 설명 #d9cdc2. 행동 강조는 #E8631F, 멤덱 보조색은 #ADB99B / #7B8E79. 카드가 놓이는 면은 흰색이고 빨강·검정 무늬는 그대로다. 경계는 얇고, 빛 번짐·유리·네온은 쓰지 않는다. 색인 선만 아주 짧게 자리 잡으며, 동작 줄이기는 그 움직임도 끈다.

## 4 Performance UI

학습 열은 약 720px, 전체 껍질은 760px을 넘지 않는다. 폰, 280px 폭, 태블릿 폭에서 같은 한 열을 쓰고 기기 이름은 적지 않는다. 버튼과 입력은 44px 이상, 주요 버튼은 48px 이상이다. 안전 영역과 키보드 여백을 두고 가로로 페이지가 넘치지 않게 한다. 기억 탭은 1 짝맞추기, 2 숫자그림, 3 궁전, 4 이야기, 5 복습이다. 각 방법은 시작·숨기기·단서·확인·다음으로 고른 스택의 실제 순서를 묻는다. 설명은 한 문장에 한 가지 행동이고, 자세한 말은 접는 안내로 보낸다.

## 5 Performance UI exception

멤덱은 공연 도구가 아닌 학습 도구다. 이번에 승인된 학습 화면 개선은 다른 앱의 공연 화면 예외를 늘리지 않는다. 외부 글꼴, 이미지 모델, 자동 재생, 전체 화면을 더하지 않는다. 서비스 워커는 기존처럼 네트워크를 먼저 보고, 매니페스트만 신선하게 검사한다. 강제 새로고침은 없다.

## 6 Forbidden changes

저장 키 `magic-memdeck-v1`과 스택 데이터 파일은 바꾸지 않는다. 퀴즈와 포카드의 채점·시간 측정, 복습 간격 1·3·7·14·30일, 원본 보호와 백업·순서 교체·설치 안내를 유지한다. 손상된 새 기억 데이터는 백업 전체를 거절해 원래 기록을 남긴다. 순서 교체는 그 스택의 장면·궁전·이야기만 지운다. 단서와 답 보기는 맞춘 기록에 넣지 않는다. 가장 빠른 방법이라는 말은 하지 않는다.

## 7 Signature detail

서명 요소는 종이 위의 카드와 펠트 위 기록면, 그리고 카드 색인 옆의 위치 번호다. 헤더의 17은 장식이 아니라, 번호로 자리를 찾는 제품의 표시다. 표의 번호도 같은 세이지색 색인으로 읽힌다.
